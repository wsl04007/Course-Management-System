Course-Management-System（课程管理系统）
项目概述
本项目旨在开发一款适配校园场景的课程管理系统，解决课程安排、选课管理、成绩管理、教学信息统计等问题，目标用户为在校学生、授课教师及教务管理人员。系统聚焦校园教务管理的核心痛点，实现课程全流程线上化、规范化管理，提升教务工作效率，为师生提供便捷的课程相关服务。
核心功能模块
1. 课程信息管理
管理员可新增、编辑、删除课程信息，设置课程名称、学分、课时、授课类型、上课时间 / 地点等核心信息；支持课程分类管理，教师可查看本人授课课程详情，学生可查看所有可选修课程信息。
2. 学生选课管理
学生可在指定选课时间段内在线选课、退课，系统自动校验选课冲突（时间冲突、学分上限、人数上限）；支持查看个人已选课程表，生成可视化课表；管理员可查看整体选课数据，处理选课异常情况。
3. 成绩管理
教师可针对授课课程录入、修改学生成绩，支持成绩批量导入 / 导出，设置成绩评定规则（平时成绩、期末成绩比例）；学生可查询个人课程成绩、绩点，系统自动计算平均绩点；管理员可审核成绩数据，统计整体成绩分布。
4. 教学信息统计
系统自动统计课程选课人数、课程完成率、学生成绩分段、教师授课工作量等数据，生成可视化报表；支持按学院、班级、学期筛选查看统计结果，为教务管理、教学评估提供数据支撑。
5. 用户信息与权限管理
区分学生、教师、管理员三类角色，实现精细化权限分级管理：
学生：可修改个人信息、重置密码、查看课表、选课、查询成绩；
教师：可管理个人授课课程、录入成绩、查看选课学生名单；
管理员：可批量管理用户账号、分配角色、审核课程与成绩、统筹教务工作。
6. 系统设置
管理员可灵活配置系统核心参数，包括选课时间、学分上限、课表规则、成绩核算标准等；支持系统日志查看、消息通知配置（选课提醒、成绩发布通知），适配不同院校的教务管理需求。

常见问题解决
选课失败：检查是否存在上课时间冲突、学分已达上限、课程人数已满，若仍有问题联系管理员；
成绩不显示：刷新页面，若未解决，检查项目启动状态及数据库连接；
账号登录异常：联系管理员重置密码或检查账号状态；
课表加载失败：检查网络连接，重新登录系统重试。
